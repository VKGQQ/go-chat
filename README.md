# Go 多人聊天系统

[![CI](https://github.com/VKGQQ/go-chat/actions/workflows/ci.yml/badge.svg)](https://github.com/VKGQQ/go-chat/actions/workflows/ci.yml)

基于 Go + Redis 的 TCP 多人聊天系统，采用 C/S 架构与自定义二进制协议，支持注册登录、群聊、私聊、在线状态广播、离线消息与本地聊天记录持久化。

## 功能特性

- **账号体系**：注册 / 登录，密码经 bcrypt 哈希后存储，恒定时间比较防时序攻击
- **群聊**：向所有在线用户广播，发送者身份由服务端会话强制确认，防伪造
- **私聊**：精准路由到目标用户；目标不在线时存入离线队列，其上线后按序投递
- **在线状态**：用户上/下线实时广播，客户端维护本地在线列表
- **重复登录互踢**：同账号新连接上线后自动踢掉旧连接
- **聊天记录**：客户端按用户分文件本地持久化（JSONL 追加写），重登自动恢复

## 技术栈

| 组件 | 说明 |
|---|---|
| Go 1.26 | 服务端与客户端实现 |
| Redis 7+ (go-redis/v9) | 账号存储（Hash）、离线消息队列（List） |
| golang.org/x/crypto | bcrypt 密码哈希 |
| 自定义 TCP 协议 | 4 字节大端长度头 + JSON 包体 |

## 快速开始

### 环境要求

- Go 1.26+
- Redis（本地或远程均可）

### 启动服务端

```bash
# 可选：配置 Redis 地址（默认 127.0.0.1:6379，无密码）
# Windows PowerShell: $env:REDIS_ADDR="192.168.1.10:6379"; $env:REDIS_PASSWORD="xxx"
# Linux/macOS:        export REDIS_ADDR=192.168.1.10:6379 REDIS_PASSWORD=xxx

go run ./chat/server/main
```

服务端监听 `0.0.0.0:8889`。Redis 连接失败会重试 5 次后退出（fail fast）。

### 启动客户端

```bash
# 从项目根目录启动（聊天记录会写入根目录下的 history/ 文件夹）
# 可选：配置服务端地址（默认 127.0.0.1:8889）
# Windows PowerShell: $env:CHAT_SERVER_ADDR="192.168.1.10:8889"

go run ./chat/client/main
```

## 协议设计

```
┌────────────────────┬──────────────────────┐
│  长度头 (4 字节)    │   包体 (JSON)         │
│  大端序 uint32      │   Message 结构体      │
└────────────────────┴──────────────────────┘
```

`Message` 为最外层信封：`Type` 标识消息类别（登录、注册、群聊、私聊、状态通知等），`Data` 承载对应消息结构体的 JSON 串。单包上限 8096 字节，超限直接拒绝。

## 工程设计要点

**并发安全**
- 每条连接独占一把写锁：帧头 + 帧体在持锁期间连续写出，多 goroutine 并发发包不会字节交错
- 在线用户表使用 `RWMutex`（读多写少），对外只返回快照副本，网络 IO 全部在锁外进行
- 互踢场景下删除在线表项前校验指针一致性，旧连接断开不会误删新连接表项

**可靠性**
- `io.ReadFull` 读满帧头与包体，杜绝 TCP 短读/半包导致的帧失步
- 包体长度先校验再分配缓冲，防御畸形包/攻击包
- 每次写入设置 5 秒写截止时间，对端卡死不会永久阻塞 goroutine
- Redis 调用统一 3 秒 context 超时；启动阶段 Redis 不可用则重试后退出，不假活
- 单连接 panic 被隔离在该连接内，不影响服务进程

**安全**
- 密码 bcrypt 哈希存储，注册时强制覆盖明文，绝不落盘
- 群聊/私聊发送者身份以服务端登录会话为准，客户端上报的 UserId 不可信
- 注册入口做边界校验：拒绝非正整数 id、空密码、空昵称
- Redis 地址、密码、服务端地址均通过环境变量配置，敏感信息不入库不入 git

## 环境变量

| 变量 | 作用端 | 默认值 | 说明 |
|---|---|---|---|
| `REDIS_ADDR` | 服务端 | `127.0.0.1:6379` | Redis 地址 |
| `REDIS_PASSWORD` | 服务端 | 空 | Redis 密码 |
| `CHAT_SERVER_ADDR` | 客户端 | `127.0.0.1:8889` | 服务端地址 |
